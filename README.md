## КАК РАБОТАЕТ
1. prepare_and_schedule.bat проверяет каждую панель, загружает и проверяет 9.wav,
   затем удаляет прежние файлы события «Открытие ключом или кодом».
   В этот момент панели остаются в режиме Online.
   Если панель отвечает «Не достаточно места для файла», программа удаляет прежние
   файлы этого события, повторяет загрузку 9.wav и обязательно проверяет результат.
2. Программа создаёт задачу Windows на указанную дату и время. Окно можно закрыть.
3. В назначенное время Планировщик переключает только успешно подготовленные панели в Offline.
4. В конце акции return_online_now.bat удаляет 9.wav, проверяет удаление и
   возвращает весь список поддерживаемых панелей в Online.
5. Пароль хранится в файле root_password.dpapi в зашифрованном виде. Расшифровать
   его может только та учётная запись Windows, которая создала расписание.

ОБЯЗАТЕЛЬНЫЙ ТЕСТ НА ОДНОЙ ПАНЕЛИ
1. Запустите test_one_panel.bat.
2. Укажите IP тестовой панели, например 10.77.171.25, и пароль root.
3. Проверьте открытие ключом.
4. Вернитесь к окну программы и нажмите Enter — панель вернётся в Online.
5. Только после успешного теста запускайте общий сценарий.

ПОДГОТОВКА И РАСПИСАНИЕ
1. запустите prepare_and_schedule.bat.
2. Укажите дату и время включения. Например: 03.09.2026 и 08:00.
3. Введите общий пароль root. При вводе пароль на экране не отображается.
4. Дождитесь окончания подготовки. После создания задачи окно можно закрыть.
5. Компьютер можно оставить в спящем режиме, но нельзя выключать или выходить
   из своей учётной записи Windows. В Windows должны быть разрешены таймеры пробуждения.

ВОЗВРАТ В ONLINE
После завершения акции запустите return_online_now.bat и введите пароль root.
Сначала программа удалит только файл 9.wav, затем вернёт ассистент в Online.
Окно нужно держать открытым только до завершения операции (обычно несколько минут).

ПРОВЕРКА
check_status.bat показывает текущий режим ассистента и список файлов каждой панели.

ЖУРНАЛЫ
sokol_mass_audio.log — читаемый журнал работы.
results.csv — результат каждой операции по каждому IP, открывается в Excel.
deployment_state.json — техническое состояние подготовленных панелей.


ВАЖНО ВАЖНО ВАЖНО ВАЖНО !!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

Не переименовывайте и не переносите отдельные файлы внутри этой папки.
Скрипт работает только с событием «Открытие ключом или кодом» и пропускает
устройства, которые не определяются как rev.5.

программа всё равно попытается вернуть панель в Online и запишет ошибку в results.csv.
